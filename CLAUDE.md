# Ashboard Vision — notes pour Claude

Ashboard Vision (identifiant technique `ashboard-vision`, dépôt `Ashewos/ashboard-vision` ; le projet s'est appelé trofeo-HB-dashboard) : tableau de bord modulaire pour l'écran USB Thermalright Trofeo Vision 9,16" (1920×462, rotation 180°), en .NET 10, SkiaSharp, xUnit. Le nom Ashboard Vision s'affiche partout ; le code garde ses noms `Trofeo.*`, et trois identifiants gardent l'ancien nom exprès : l'entropie DPAPI, `FreeboxSource.AppId` et `LayoutTransfer.Format`. Alex, le propriétaire, parle français : on lui répond en français, et les textes affichés à l'écran le tutoient.

## Pièges connus

- **Windows, mais testable sous Linux** : les projets ciblent `net10.0-windows` (WinForms, WinRT, LibreHardwareMonitor, WinUSB). Sous Linux, la plupart des projets de tests se construisent et tournent quand même (`dotnet test tests/<projet>`), grâce à `EnableWindowsTargeting` et au paquet natif Skia pour Linux, tous deux conditionnés à Linux. Échecs connus : DPAPI et police de secours (pas de polices système) dans Core et Network, `cmd.exe` dans Sensors, et Display.Tests qui demande le runtime Windows Desktop. L'écran réel, Media Foundation, WinRT et les raccourcis clavier restent à vérifier sur le PC d'Alex.
- **Application Claude empaquetée (MSIX)** sur le PC d'Alex : ce qui est lancé depuis les terminaux de Claude écrit `%AppData%` dans une copie privée (`%LocalAppData%\Packages\Claude_…\LocalCache\Roaming`). Pour changer ses vrais réglages (`%AppData%\ashboard-vision` ; `%AppData%\trofeo-HB-dashboard` avant le déménagement que fait la version du plan 6 à son premier lancement), lui donner une commande à lancer dans son propre terminal. Pour lire ses vrais fichiers (journal, `layout.json`), passer par `\\localhost\C$\Users\%USERNAME%\AppData\Roaming\…`. Pour lancer le service comme lui, `explorer.exe <chemin de Trofeo.Display.exe>`, avec son accord.
- **Essais d'apparence avec Alex** : lui donner la fonction de séance du bilan du plan 4 (elle arrête le service, applique `--appearance`, relance toujours), et écrire les nombres avec un point (`opacity=0.5`) : PowerShell coupe `0,5` quand une fonction relaie `@args`. Les réglages ne sont lus qu'au démarrage du service.
- Le service démarre avec Windows si l'interrupteur des Paramètres est mis (valeur `Run` de HKCU, nommée `ashboard-vision`, vers `src\Trofeo.Display\bin\Release\net10.0-windows10.0.19041.0\Trofeo.Display.exe`). **Construire en Release** demande d'arrêter le service et de fermer la fenêtre de réglage : les deux verrouillent leurs fichiers.
- **Quotas de Claude Code en retard** : le mod ne voit que les réponses reçues sur ce PC. Ce qui est consommé ailleurs (chat cloud, claude.ai) n'apparaît qu'à la prochaine réponse locale. C'est voulu (voir le bilan du plan 5).
