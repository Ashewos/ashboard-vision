## Décisions

Chaque décision est suivie de son coût si elle est fausse.

- **Inno Setup 7.1.1** (installateur 64 bits, en administrateur) au lieu de Velopack, choisi par Alex. Coût : pas de mise à jour différentielle, l'installateur complet (49 Mo) est retéléchargé.
- **PawnIO téléchargé pendant l'installation** (adresse officielle, version et SHA-256 fixés), pas embarqué : sa redistribution n'est pas claire. Coût : sans Internet, les températures attendent une réinstallation.
- **Pas de signature de code** ; captures SmartScreen abandonnées (Alex), le README décrit les deux clics en texte. Coût : un avertissement qui peut faire peur.
- **Canal par défaut** : Bêta si la version installée est une bêta, Stable sinon (validé par Alex). Coût : aucun connu.
- **Tout numéro avec « - » est une bêta** : la recette exige `Canary` et publie en préversion. Coût : une future `rc` serait publiée en préversion, ce qui est sans doute voulu.
- **Le mod des quotas ne revient pas seul** après une désinstallation puis une réinstallation : le bouton « Installer le mod des quotas » le remet (Alex : « logique »). Coût : un clic.
- **« Lancer » et les raccourcis ouvrent la fenêtre**, qui démarre le service s'il ne tourne pas ; le démarrage avec Windows ne lance que le service. Coût : aucun connu.
- **L'installateur demande lui-même l'autorisation** (`d441204`) : lancé déjà élevé (`runas`), il ne pouvait pas relancer le service avec l'utilisateur d'origine, et le service tournait en administrateur après une mise à jour. Le lanceur attend la fin de l'installateur (10 minutes au plus) : code 2 = annulé, autre code non nul = échec. Prouvé par Alex : refus → code 2, accord → service non élevé. Coût : si un installateur reste ouvert plus de 10 minutes, la fenêtre le croit lancé.
- **Badge de version du README avec `include_prereleases`** : sans lui, il n'affiche rien tant qu'il n'y a que des bêtas. À revoir à la `1.0.0`.
- **Le nom Freebox de l'application devient « Ashboard Vision »** ; seul `FreeboxSource.AppId` garde l'ancien nom, l'autorisation tient à lui. Vérifié : la Freebox reste autorisée.

## Astuces trouvées pendant le plan

- **Bac à sable Windows** pour essayer l'installateur sans toucher au PC : fichiers `.wsb` et scripts dans `installer/bac-a-sable/` (ignoré par git), journaux dans `installer/bac-a-sable/journaux`.
- **`Start-Process -Wait`** de PowerShell attend aussi les processus enfants (le service relancé) : pour lire le code de sortie de l'installateur, ne pas s'y fier.
- **`workflow_dispatch`** ne marche que si la recette existe sur la branche par défaut.
- **Les machines de GitHub lancent les tests en administrateur** : un test qui dépend de l'élévation doit suivre l'élévation réelle.
- **Élévation d'un processus** : `OpenProcess(0x1000)` puis `GetTokenInformation(TokenElevation)` ; un `Path` vide dans `Get-Process` trahit déjà un processus élevé.
