L'image d'accueil animée : les trois thèmes en motion design

Écran incliné à 10°, lueur Ambilight moyenne. Toutes les 4 secondes, le thème change en glissant, la lueur prend ses couleurs, un reflet balaie la vitre et le nom du thème s'affiche. L'écran oscille très légèrement de gauche à droite. Ici c'est une animation du navigateur ; sur GitHub, ce sera un fichier animé fabriqué par le projet à partir de vraies images de l'écran.
